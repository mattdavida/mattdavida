## Highlighted Projects

### Markets and AI

Reference work for trading operations, human-in-the-loop systems, and grounded model integration.

- [polyglot-execution-agent](https://github.com/mattdavida/polyglot-execution-agent) — Trading desk proof of concept: LangGraph and Azure OpenAI for strategy, a C++20 limit-order-book engine for slippage, with human approval before dispatch.
- [grounded-ai-reference-architecture](https://github.com/mattdavida/grounded-ai-reference-architecture) — Chat and voice in operational software without exposing raw data to the model.
- [intelligent-trade-exception-triage-engine](https://github.com/mattdavida/intelligent-trade-exception-triage-engine) — Human-in-the-loop middle-office exception triage.
- [real-time-market-intelligence-pipeline](https://github.com/mattdavida/real-time-market-intelligence-pipeline) — Treasury futures ticks through Kafka and kdb+/q, surfaced on an Angular desk over SSE.

### Game tooling

Installers, shared UI, and in-game tools for Unreal and Unity titles.

- [ue4ss-Installer](https://github.com/mattdavida/ue4ss-Installer) — Desktop app for installing UE4SS into Unreal games. Select a Steam title, choose Release or zDev, optionally add a community mod zip.
- [BepInEx-Installer](https://github.com/mattdavida/BepInEx-Installer) — Desktop app for installing BepInEx into Unity games, with optional plugin zip support.
- [ue4ss-ModMenu](https://github.com/mattdavida/ue4ss-ModMenu) — UI framework for UE4SS Lua mods so feature modules can register in-game settings panels without each mod building its own shell.
- [SilkSongMod](https://github.com/mattdavida/SilkSongMod) — In-game tools and settings UI for Hollow Knight: Silksong.
